RepoShep Privacy Policy

生效日期：2026 年 10 月 15 日 · 适用于 Mac App Store 分发的 RepoShep for macOS 1.0 及更高版本

Effective date: October 15, 2026 · Applies to RepoShep for macOS 1.0 and later, distributed on the Mac App Store

摘要

  • 我们不收集任何数据。没有账号，没有遥测、分析、广告或追踪，开发者不运营任何服务器。
  • 核心功能完全在你的 Mac 上本地运行：仓库状态、差异、健康分与活动记录只保存在本机。
  • 仅存在两条可选的出站网络路径，均默认关闭，且都需要你显式开启：远端刷新（git fetch）与 AI 功能。

1. 我们收集的信息：无

RepoShep 不收集、不传输、不出售任何个人数据。应用没有用户账号体系，不内嵌任何遥测、分析或崩溃上报组件，不含广告或追踪器。如你在 macOS 系统设置中开启了崩溃报告，相关数据由 Apple 按 Apple 的隐私政策处理，与本应用无关。

2. 保存在你 Mac 上的数据

以下数据只存储在你的 Mac 上（应用沙盒容器内），不上传、不同步：

  • 你授权的文件夹与对应的安全作用域书签；
  • 仓库列表、分组、收藏与偏好设置；
  • Git 状态、差异缓存、健康分、状态持续时间与活动记录；
  • 运行时缓存。

唯一的例外：你在 AI 设置中填写的 API Key 保存在 macOS 钥匙串（Keychain）中，不写入普通文件。卸载应用即删除上述沙盒内数据；钥匙串中的条目可随时在设置中清除。

3. 系统权限的使用

  • 文件夹访问：RepoShep 运行于 App Sandbox，只能访问你通过系统文件选择器明确选择的文件夹。授权以安全作用域书签形式记住，用于重启后恢复访问；你可以随时移除授权。应用不会请求全盘访问。
  • 网络：默认配置下，应用不产生任何网络请求。仅当你开启下述可选功能时，应用才会发起出站连接。

4. 可选出站路径一：远端刷新（git fetch）

此功能默认关闭，开启需要总开关与首次功能披露双重确认。它对你的仓库远端执行唯一的 Git 写操作 git fetch，用于刷新本地的远端跟踪引用，使「超前 / 落后」与「远端状态更新时间」反映远端最新状态。

  • 传输内容：仅为 Git 传输协议本身所需的信息（远端地址与 Git 协议握手数据）。不包含源码内容、差异文本或任何健康数据。
  • 写入范围：仅写入库的 .git 目录（位于你授权的文件夹内），从不修改你的工作区文件。
  • 协议边界：仅支持 HTTPS 远端；SSH 等其它协议不会在应用内执行，而是引导你使用自己的终端。永不执行 push、pull、clone 或其它任何 Git 写操作。
  • 凭据：RepoShep 不创建、不存储 Git 凭据。如远端需要认证，由 Git 自身的钥匙串凭据助手（osxkeychain）按 Git 的既有机制处理，凭据不会写入仓库配置。

5. 可选出站路径二：AI 功能

AI 功能默认关闭。你需要在设置中自行配置一个 OpenAI 兼容的服务端点（地址、模型与 API Key）。请求由应用直接发往你配置的端点：开发者不经手、不代理、不可见。三项 AI 功能发送的内容各不相同：

5.1 状态解读

发送一组结构化事实：仓库文件夹名、分支名、健康状态、状态持续时间、超前/落后计数、改动/未跟踪/冲突文件数、增删行数，以及至多 50 个改动文件路径（超出会截断并告知总量）。从不发送文件内容、diff 正文、远程 URL 或绝对路径。

5.2 改动总结

在你对每一次请求逐一确认后，发送该仓库当前改动的真实 diff 文本（单次上限 48 KB，超出部分截断并明确标注）。diff 是你的代码原文——是否发送，由你逐次决定。

5.3 命令助手

发送你的自然语言问题与上述仓库状态事实。返回的命令建议仅用于复制或在终端打开：RepoShep 永不自动执行任何命令。

你的 API Key 只保存在 macOS 钥匙串。发送给 AI 服务商的内容还受该服务商自身隐私政策约束，请选择你信任的服务商。

6. 诊断报告与日志脱敏

「导出诊断报告」由你主动触发，保存到你选择的位置。报告不包含源码、diff、凭据或令牌。远程 URL 在进入界面、日志或诊断之前，其中内嵌的用户名、令牌与密码一律剥离；报告中的用户路径也会做脱敏处理。

7. 第三方服务

开发者不运营任何后端服务。若你启用远端刷新或 AI 功能，涉及的服务器（Git 托管服务商、AI 服务商）完全由你自行选择与配置，这些交互适用其各自的隐私政策。

8. 儿童隐私

RepoShep 是面向开发者的工具，不面向儿童，也不有意收集任何用户的个人数据。

9. 数据安全

应用运行于 macOS App Sandbox，按最小权限申请系统能力；对仓库的访问仅限你明确授权的范围；出站连接仅限于上述两条可选路径。核心功能不依赖任何联网能力。

10. 政策变更

如隐私政策发生变化（例如未来加入新的可选联网功能），我们会在本页更新并修改生效日期；涉及新数据流的功能会在应用内同步披露并默认关闭。

11. 联系我们

如对隐私政策有任何疑问，请联系：support@example.com。

Summary

  • We collect nothing. No accounts, no telemetry, no analytics, no ads, no tracking, and no developer-operated servers.
  • Core features run entirely and locally on your Mac: repository status, diffs, health scores and activity logs stay on your machine.
  • There are exactly two optional outbound network paths, both off by default, each requiring your explicit opt-in: remote refresh (git fetch) and the AI features.

1. Information we collect: none

RepoShep does not collect, transmit, or sell any personal data. The app has no user accounts, embeds no telemetry, analytics, or crash-reporting SDKs, and contains no ads or trackers. If you have enabled crash reporting in macOS system settings, that data is handled by Apple under Apple's privacy policy and is unrelated to this app.

2. Data stored on your Mac

The following data is stored only on your Mac, inside the app's sandbox container. It is never uploaded or synced:

  • Your authorized folders and their security-scoped bookmarks;
  • Your repository list, groups, favorites, and preferences;
  • Git status, diff caches, health scores, state durations, and activity logs;
  • Runtime caches.

The one exception: the API key you enter in AI settings is stored in the macOS Keychain, never in plain files. Uninstalling the app removes the sandbox data above; the Keychain entry can be cleared from settings at any time.

3. System permissions

  • Folder access: RepoShep runs inside App Sandbox and can only access folders you explicitly select in the system file picker. Authorization is remembered via security-scoped bookmarks so access survives relaunch, and you can revoke it at any time. The app never requests Full Disk Access.
  • Network: With default settings the app makes no network requests at all. Outbound connections occur only when you enable the optional features below.

4. Optional outbound path 1: remote refresh (git fetch)

This feature is off by default and requires a two-step consent: a master switch plus a first-run disclosure. It performs the app's single sanctioned Git write operation, git fetch, so that "ahead / behind" and "remote last refreshed" reflect the latest remote state.

  • What is transmitted: only what the Git transfer protocol itself requires (the remote address and Git protocol handshake data). It never includes source code, diff text, or any health data.
  • What is written: only the repository's .git directory (inside your authorized folder). Your working tree files are never modified.
  • Protocol boundary: HTTPS remotes only. SSH and other schemes are never executed in-app; you are guided to your own terminal instead. The app never performs push, pull, clone, or any other Git write operation.
  • Credentials: RepoShep does not create or store Git credentials. If a remote requires authentication, Git's own Keychain credential helper (osxkeychain) handles it under Git's standard mechanism; credentials are never written into repository config.

5. Optional outbound path 2: AI features

The AI features are off by default. You configure your own OpenAI-compatible endpoint (URL, model, and API key) in settings. Requests go directly from the app to your configured endpoint: the developer never sees, proxies, or relays them. The three AI features send different things:

5.1 State interpretation

Sends a set of structured facts: the repository folder name, branch name, health state, state duration, ahead/behind counts, changed/untracked/unmerged file counts, insertion/deletion line counts, and up to 50 changed file paths (capped, with the total disclosed). It never sends file contents, diff bodies, remote URLs, or absolute paths.

5.2 Change summary

After you explicitly confirm each individual request, it sends the repository's actual diff text (48 KB per request, truncated and clearly labeled beyond that). The diff is your code verbatim — whether to send it is your per-request decision.

5.3 Command assistant

Sends your natural-language question together with the structured facts above. The suggested command it returns is for copying or opening in Terminal only: RepoShep never executes any command automatically.

Your API key is stored only in the macOS Keychain. What AI providers do with the content you send is governed by their own privacy policies — choose a provider you trust.

6. Diagnostic reports and log redaction

"Export Diagnostic Report" runs only when you trigger it, and saves to a location you choose. The report never contains source code, diffs, credentials, or tokens. Remote URLs have any embedded username, token, or password stripped before they reach the UI, logs, or diagnostics, and user paths in reports are redacted.

7. Third-party services

The developer operates no backend services. If you enable remote refresh or the AI features, the servers involved (your Git host and your AI provider) are entirely your own choice and configuration; those interactions are governed by their respective privacy policies.

8. Children's privacy

RepoShep is a developer tool. It is not directed at children and does not knowingly collect personal data from any user.

9. Data security

The app runs inside the macOS App Sandbox and requests system capabilities on a least-privilege basis. Repository access is limited to folders you explicitly authorize, and outbound connections are limited to the two optional paths described above. Core functionality requires no network access.

10. Changes to this policy

If this policy changes (for example, if a new optional networked feature is added in the future), we will update this page and revise the effective date. Features involving new data flows will be disclosed in-app and off by default.
